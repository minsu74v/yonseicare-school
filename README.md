# yonseicare-school

원주연세재가복지센터 평가 면담 준비 페이지입니다.

## 질문/답변 수정 방법

`questions.js` 파일만 수정하면 됩니다.

각 문항은 아래 네 부분을 주로 수정합니다.

- `question`: 질문 문장
- `answer`: 답변 문장
- `qHighlights`: 질문에서 파란색으로 강조할 문구
- `highlights`: 답변에서 파란색으로 강조할 문구

답변은 쉼표(,) 또는 문장이 바뀌는 부분에서 화면상 자동으로 줄바꿈됩니다.

## 진행 방식

- `알겠어요`는 초록색
- `한 번 더 볼래요`는 노란색
- 아무 선택을 하지 않은 문제도 다음 바퀴에서 다시 표시
- 마지막 문제까지 끝나면 아직 초록색이 아닌 문제만 다시 학습
- 모든 문제가 초록색이 될 때까지 반복 가능

## 3차 화면 구성

- 첫 화면에 안내문과 `학습 시작하기` 버튼 표시
- 답 확인 전에는 선택 버튼 숨김
- 답 확인 카드는 더 크게 표시
- 모든 문항을 `알겠어요`로 완료하면 `처음부터 다시 하기` 버튼 표시
