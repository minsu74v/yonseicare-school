# yonseicare-school

원주연세재가복지센터 평가 면담 준비 페이지입니다.

## 질문/답변 수정 방법
`questions.js` 파일만 수정하면 됩니다.

각 문항은 아래 네 부분을 주로 수정합니다.

- `question`: 질문 문장
- `answer`: 답변 문장
- `qHighlights`: 질문에서 파란색으로 강조할 문구
- `highlights`: 답변에서 파란색으로 강조할 문구

예:
```js
{
  question: "노인학대 예방에 대해 설명해주세요.",
  answer: "어르신 상태를 살피고 존중하며 존댓말을 사용합니다.",
  qHighlights: ["노인학대 예방"],
  highlights: ["살피고", "존중", "존댓말"]
}
```

`highlights` 안에서 문구를 삭제하면 파란색 강조가 사라지고,
새 문구를 추가하면 해당 문구가 파란색으로 표시됩니다.
