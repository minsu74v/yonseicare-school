# yonseicare-school

원주연세재가복지센터 평가 면담 준비 페이지입니다.

## 질문/답변 수정 방법
`questions.js` 파일만 수정하면 됩니다.

- `question` : 질문 문구
- `answer` : 답변 문구
- `qHighlights` : 질문에서 파란색으로 강조할 문구
- `highlights` : 답변에서 파란색으로 강조할 문구
- 답변에서 `\n`을 입력하면 그 위치에서 줄바꿈됩니다.

질문/답변은 `질문응답정리.xlsx` 원문을 기준으로 반영되어 있습니다.

## 글자 크기
학습을 시작할 때는 항상 기본 글자 크기로 시작합니다.
`가+ 글자 크게` 버튼을 누르면 크게, 다시 누르면 `가+ 글자 작게`로 표시되며 원래 크기로 줄일 수 있습니다.


## 7차 변경사항
- 최신 엑셀의 문구/줄바꿈/빨간색 강조를 반영했습니다. 빨간색은 사이트에서 파란색으로 표시됩니다.
- 이미 선택한 문제는 답을 열기 전에도 현재 상태를 표시합니다.
- 답변 카드를 누르면 다시 '답 확인하기' 화면으로 돌아갑니다.
- '알겠어요 / 한 번 더 볼래요' 버튼은 답을 확인한 뒤에만 표시됩니다.
